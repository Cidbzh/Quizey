# Quizey

**Plus tu quiz, plus tu sais.**

Quizey, c'est la révision du lycée dans votre navigateur. Un seul fichier à ouvrir, pas de compte, pas d'installation, et rien de ce que vous faites ne quitte votre machine.

![L'accueil, matière maths](img/accueil-maths.png)

## Particularité

- **Programmes officiels** — maths et physique-chimie suivent les programmes officiels de chaque année ; les langues couvrent A2 · A2+ · B1.
- **Révision par répétition espacée** — une méthode éprouvée : les questions que vous ratez reviennent vous voir, celles que vous maîtrisez s'éloignent d'elles-mêmes.
- **Jamais la même question** — chaque exercice est nouveau, avec des nombres que vous n'avez jamais vus.
- **Corrigés qui font apprendre** — chaque réponse est expliquée par la méthode, avec un dessin quand c'est possible.
- **Vos points faibles** — Quizey repère où vous réussissez le moins bien et vous propose de vous y entraîner.
- **Un niveau par matière** — une progression motivante, qui ne bloque jamais rien.

## Les matières

- **Mathématiques** (spécialité) — Seconde · Première · Terminale, avec en Terminale une option de chapitres avancés (« Maths expertes »).
- **Physique-chimie** — Seconde · Première · Terminale.
- **Allemand** et **Anglais** — trois niveaux (A2 · A2+ · B1), questions à choix multiples.

![Une question, son visuel, puis le corrigé](img/question-correction.png)

## Comment s'en servir

1. Choisissez une **matière**, une **année** (ou un niveau pour les langues) et un **thème** — ou laissez Quizey vous proposer un mélange.
2. Répondez à votre rythme. Bonne réponse, on passe à la suite ; mauvaise, le corrigé vous explique et la question reviendra vous voir.
3. Revenez quand vous voulez : votre liste « à réviser » est toujours là, avec un aperçu du temps qu'elle représente.

Le bouton « Passer » n'est pas pénalisant : vous pourrez retrouver la question plus tard.

![Le mode allemand — questions à choix multiples](img/accueil-allemand.png)

## Niveau Quizey

Chaque matière a son propre niveau. Chaque bonne réponse vous fait gagner de l'expérience, et à chaque palier une petite animation vous félicite. C'est fait pour vous motiver, pas pour vous bloquer.

## L'obtenir

**Sur ordinateur**

```bash
git clone https://github.com/Cidbzh/Quizey.git
```

puis ouvrez `Quizey/Quizey.html` (double-clic).

**Plus simple**

Téléchargez le fichier depuis la page [Releases](https://github.com/Cidbzh/Quizey/releases), puis double-cliquez sur `Quizey.html`.

Une fois en votre possession, le fichier vous appartient : clé USB, médiathèque, labo du lycée — où que vous soyez, avec ou sans internet.
